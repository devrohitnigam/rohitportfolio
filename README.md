## 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

Navigate to the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```

---

## 🏗 Build for Production

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
